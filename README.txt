# My AiPri Collection

ピンク×黒のアイプリカード管理サイトです。

## できること
- カード登録（カード名、キャラクター、コーデ、レアリティ、シリーズ、所持枚数、写真、メモ）
- 所持枚数・カード種類・ダブり枚数の集計
- 写真付き図鑑／表形式データベース
- 検索、レアリティ絞り込み、お気に入り
- JSONバックアップ（カード写真を含む）と復元
- iPhoneホーム画面への追加（公開URLで開いた場合）

## まず試す
index.html をSafariで開くか、無料ホスティングにアップロードしてHTTPSのURLで開きます。
一部のiPhone環境ではローカルファイルからの起動で保存やPWA機能が制限されるため、HTTPSでの利用を推奨します。

## 無料で公開する例：GitHub Pages
1. GitHubでアカウントを作成し、新しいリポジトリを作成します。
2. このZIPを解凍し、index.html / manifest.webmanifest / sw.js をリポジトリ直下にアップロードします。
3. リポジトリの Settings → Pages → Build and deployment で「Deploy from a branch」を選び、main / root を指定して保存します。
4. 表示された `https://ユーザー名.github.io/リポジトリ名/` のURLをiPhoneのSafariで開きます。
5. Safariの共有ボタン →「ホーム画面に追加」でアイコンを追加できます。

## プライバシーと注意
GitHub Pagesで公開したページは、URLを知る人が開ける公開ページです。サイトのソースも公開されます。
カードデータ・写真はIndexedDBを使って、そのブラウザ／端末内に保存します。サイト運営者のサーバーには送信しませんが、同じブラウザのデータを消すと失われることがあります。
「自分専用」はアカウント認証によるアクセス制限を意味しません。URLを知られたくない場合や厳密な非公開が必要な場合は、公開ホスティングを使わず端末内で利用する方法、または認証付きホスティングを検討してください。
端末変更・Safariの履歴とWebサイトデータ消去・故障に備え、定期的にバックアップを保存してください。バックアップJSONには登録したカード写真も含まれるため、他人に送らないでください。
写真は5MB以下を推奨します。大きな写真を多数登録するとブラウザの保存容量に達する場合があります。
